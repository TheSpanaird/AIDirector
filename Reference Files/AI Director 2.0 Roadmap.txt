Non-Negotiable Design Principles
1. Narrative Is Canon

Narrative Director produces:

NarrativeRecord


containing:

History
Premise
Current Situation
Factions
Threats
Mysteries
Occupancy Story
Player Goals

No downstream system may contradict narrative canon.

2. Narrative Drift Is Forbidden

Subsystems may:

Expand
Interpret
Implement

Subsystems may not:

Rewrite
Retcon
Replace
Contradict

canonical narrative.

3. Regeneration Must Be Local
Bad Map?
    Regenerate Map

Bad Sector?
    Regenerate Sector

Bad Entity?
    Regenerate Entity

Bad Placement?
    Regenerate Placement


without affecting:

Lore
History
Factions
Mysteries
Narrative
4. Structured Data Over Prose

Every stage outputs:

Machine-readable structured data


No subsystem should scrape generated prose.

7. AI Work Must Be Partitioned

Hermes 3 is a bounded-context model.

Large facilities must be generated through deterministic passes.

No AI subsystem should generate:

All Sectors
All Descriptions
All NPCs
All Loot
All Clues
All Anchors

in a single prompt.

Generation must be partitioned into:

Narrative Pass
        ↓
Architectural Pass
        ↓
Manifest Pass
        ↓
Sector Passes
        ↓
Entity Passes
        ↓
Anchor Passes


Benefits:

Smaller Prompts
Lower Hallucination Rate
Better Determinism
Better Regeneration
Better Scaling
Reduced Scene Manager Complexity
8. One Stage, One Responsibility

Every subsystem answers one question.

Narrative Director
    What happened?

Map Architect
    What kind of place is this?

Scene Sector Planner
    What sectors exist?

Building Program Planner
    How is the structure organized?

Architectural Manifest Builder
    How is everything connected?

Architectural Grammar
    How should this be interpreted architecturally?

Cartographer
    What geometry should exist?

Scene Record Builder
    What information is tracked per sector?

Sector Writer
    What is this sector like?

Entity Planner
    What exists here?

Spatial Anchor Planner
    What is everything doing?

Token Placement Planner
    Where does everything go?


No stage should answer multiple responsibilities simultaneously.

ARCHITECTURAL DISCOVERY
-----------------------

FortifiedSiteGrammar currently
contains mixed responsibilities.

Semantic Architecture:
- detachedBuildings
- openAreas
- keepAccessRoute
- population structures
- wall systems

Geometry:
- cells
- polygons
- wall coordinates

Long-term direction:

Move semantic architecture into
ArchitecturalManifest.

Leave geometry generation inside
FortifiedSiteGrammar.

SPRINT 13 DISCOVERY
-------------------

ArchitecturalManifestBuilder
must remain archetype-agnostic.

It must not contain:

- Castle logic
- Temple logic
- Prison logic
- Hospital logic
- Spaceport logic

LayoutProfileLibrary remains
the architectural source of truth.

Architectural Grammars remain
the geometry source of truth.

ManifestBuilder assembles
canonical planning data and
topology contracts between the two.
