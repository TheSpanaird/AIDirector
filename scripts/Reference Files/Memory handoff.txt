Architectural Pivot

During discussion the real issue emerged.

Not:

Narrative generation


but:

Memory architecture

Key Learning
Campaign History != Campaign Memory

Current journals contain:

Scene descriptions
Sector descriptions
Room descriptions
Atmospheric details
Manifest exports
Generation logs


Example:

Room was dusty.
Cobwebs on walls.
Dim lighting.
Broken archway.


Those facts are not useful in scene 40.

Example That Drove Design

Scenario:

Scene 2

Players help a blacksmith.


Scene 40:

Players need armor repaired.


AI should remember:

Blacksmith
Relationship
Favor owed
Location


AI should NOT remember:

Cobwebs in corner
Lighting conditions
Floor debris

Proposed Conceptual Memory Model
Layer 1

Active Narrative Memory

Contains:

Current objectives
Current threats
Current mysteries
Current arc
Current factions


Small.

Always loaded.

Layer 2

Entity Memory

Contains:

NPCs
Locations
Organizations
Relationships
Obligations


Example:

{
  "name": "Garrick Ironhand",
  "role": "Blacksmith",
  "owedFavor": true,
  "relationship": "Friendly"
}


Persists forever.

Layer 3

Campaign Archive

Contains:

Everything


Journal history.

Recaps.

Scene records.

Manifests.

Not loaded automatically.

Only searched when necessary.
